# CafeX Communications

> CafeX Communications, Inc. (founded 2013) builds a low-code platform for intelligent applications
> and agentic systems in regulated industries — banking, insurance, healthcare and government. The
> CafeX AI platform is delivered as multi-tenant SaaS and organised into App Studio, Data Studio and
> Agent Studio. CafeX publishes exactly one public, callable API: the CafeX Audit Events API.
>
> This file was generated by API Evangelist from public sources on 2026-08-08. CafeX does not
> publish an llms.txt of its own (https://cafex.ai/llms.txt returns 404).

## APIs

- [CafeX Audit Events API](https://support.cafex.com/support/solutions/articles/73000645442-accessing-audit-information-programmatically): Tenant-scoped REST search over audit event data. `POST https://app.cafex.com/audit-search-rest/search`, JSON body, OAuth 2.0 client-credentials bearer token. Required: `page.pageSize` (max 100), `timestampFrom`, `timestampTo`. Optional filters: `service`, `type`, `action`, `message`, `miniAppId`, `trackId`, `conferenceSessionId`, `userId`, `changes`, `secondaryAttributes`, `sortDirection`. Cursor pagination via `page.continuationToken`. Events retained 1 year.

## Authentication

- [Token endpoint](https://support.cafex.com/support/solutions/articles/73000645442-accessing-audit-information-programmatically): `POST https://auth.cafex.com/authserver/token` as `application/x-www-form-urlencoded` with `grant_type=client_credentials`, `client_id`, `client_secret`. Returns `access_token`, valid 8 hours. Use as `Authorization: Bearer {token}`. No scopes are defined.
- Client IDs and secrets are issued inside the authenticated product at Tenant settings > Management > Client applications. There is no anonymous developer sign-up that yields API credentials.

## Specs

- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL or MCP manifest is published by CafeX. Probed and confirmed 2026-08-08 across cafex.ai, app.cafex.com, auth.cafex.com and support.cafex.com.
